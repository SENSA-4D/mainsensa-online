# SENSA4D

Landing page statis yang dikembangkan untuk menghadirkan akses cepat, tampilan responsif, dan pengalaman pengguna yang nyaman di berbagai perangkat. Dibangun menggunakan teknologi web modern dengan struktur yang ringan sehingga mudah dikelola dan dikembangkan.

🚀 **Live Demo:** [Kunjungi Website di Sini](https://sensa-4d.github.io/mainsensa-online/)

---

## ✨ Fitur Utama

- **Tampilan Responsif:** Menyesuaikan ukuran layar secara otomatis pada perangkat desktop, tablet, maupun smartphone.
- **Akses Cepat:** Menggunakan struktur halaman yang ringan sehingga proses pemuatan menjadi lebih efisien.
- **Antarmuka Modern:** Desain sederhana, bersih, dan mudah digunakan oleh setiap pengunjung.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** – Menyusun struktur halaman yang terorganisir dan mudah dipahami.
- **CSS3** – Mengatur tampilan visual, tata letak, serta elemen antarmuka.
- **JavaScript** – Menambahkan interaksi dan fungsionalitas agar halaman lebih dinamis.

---

## 📁 Struktur Repositori

- **AMP/** – Berisi aset dan file utama yang digunakan oleh website.
- **README.md** – Dokumentasi singkat mengenai proyek ini.
